# project-2-main

## AI Shift Scheduler — Enterprise Dashboard

Full-stack shift management system with AI-powered scheduling.

### Tech Stack
- **Backend**: FastAPI (Python) + SQLite
- **Frontend**: React + Vite + Tailwind CSS v4 + Framer Motion
- **AI Engine**: Custom scheduling algorithm with weekly-off rotation and leave replacement

### Setup
```bash
# Backend
cd backend
pip install -r requirements.txt
python main.py

# Frontend
cd frontend
npm install
npm run dev
```

### Default Login
- **Admin**: `admin` / `admin123`
- **Manager**: `manager` / `manager123`
- **Supervisor**: `supervisor` / `supervisor123`
